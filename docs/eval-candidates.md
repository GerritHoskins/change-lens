# Tender revision-pair candidates (web / digital / design work)

**Status:** D-3 input, not yet the evaluation manifest. Each pair must be read and anonymised before it gets a P-ID and a SHA-256 hash in the manifest ([07 §2](07-eval-dataset.md)). Source documents are never committed.

Research date: 2026-10-30. Method: web search plus direct checks of public procurement APIs (Find a Tender OCDS API, Contracts Finder OCDS release JSON). No documents were saved to disk. Most US/Canadian PDFs could not be text-extracted with the fetch tool, so the "what changed" notes come from search-engine extracts of each PDF and from the OCDS JSON. Spot-read each PDF before you add the pair to the test set.

**Confidence:** *confirmed* = I saw both the original and the amendment URL in search results or API output, and the amendment is identified as belonging to that solicitation. *probable* = I confirmed the amendment, but the original URL is missing, inferred, or only reachable through a notice page or portal.

**Licence:** UK notices: the FTS and Contracts Finder OCDS API responses carry `license: Open Government Licence v3`. That covers the notice data. Attached buyer documents are usually Crown or public-body copyright, so check before you redistribute them. US, Canadian and non-profit documents: no licence statement, so treat them as unclear and use them for internal evaluation only.
